# 쉬운방송

핸드폰을 카메라로 쓰고, 버튼 하나로 유튜브 예배 방송을 시작하는 프로그램입니다.

- 홈페이지: https://backhung65-cpu.github.io/easy-live/
- 내려받기: [Releases](https://github.com/backhung65-cpu/easy-live/releases/latest)
  - 윈도우: `EasyLive-Windows.zip`
  - 맥(애플 칩, 시험판): `EasyLive-Mac-AppleSilicon.tar.gz`
  - 맥(인텔, 시험판): `EasyLive-Mac-Intel.tar.gz`

개발: 목회ai연구소

이 프로그램에는 Node.js와 FFmpeg(GPL, https://ffmpeg.org)가 함께 들어 있습니다.
